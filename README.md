# 🚚 TNS Food Delivery System – Delivery Module

A Java Spring Boot REST API module developed as part of the TNS Food Delivery System.

## 📌 Project Overview

The Delivery Module is responsible for handling delivery-related operations in the food delivery application. It provides REST APIs for managing delivery-related data and interacting with other components of the system.

## ✨ Key Features

- RESTful API development using Spring Boot.
- Delivery-related data management.
- Create and retrieve delivery records.
- Backend processing using Java.
- API testing using Postman.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Java | Backend programming |
| Spring Boot | Application framework |
| Spring Web | REST API development |
| Spring Data JPA | Database interaction |
| Maven | Dependency management |
| Postman | API testing |
| Eclipse IDE | Development environment |

```text
└── .gitignore
```

## 🔗 API Endpoints

The following endpoints were implemented and tested:

| HTTP Method | Endpoint | Description |
|---|---|---|
| POST | `/api/delivery/persons` | Create a delivery person |
| GET | `/api/delivery/persons` | Retrieve delivery persons |

## 🧪 API Testing

The REST APIs were tested using Postman.

Successful test results included:

- `201 Created` – Delivery person creation.
- `200 OK` – Retrieving delivery persons.

## ⚙️ Installation and Setup

### Prerequisites

- Java Development Kit (JDK)
- Eclipse IDE or another Java IDE
- Maven
- Postman

### 1. Clone the repository

```bash
git clone https://github.com/krupaelon/TNS-Food-Delivery-Delivery-Module.git
```

### 2. Open the project

Import the project into Eclipse as an existing Maven project.

### 3. Install dependencies

Run:

```bash
mvn clean install
```

### 4. Run the application

Locate `FoodDeliveryApplication.java` and run it as a Java Application or Spring Boot Application.

### 5. Test the APIs

Open Postman and test the available REST endpoints.
